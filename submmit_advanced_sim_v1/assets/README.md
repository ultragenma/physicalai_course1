# 評価用アセット

このフォルダは説明資料専用です。実演ごとの画像・マスク・実験JSON・校正情報は、Git管理外の`artifacts/<run_id>/`へ保存してください。実データには個人情報や社内情報が含まれる可能性があるため、GitHub公開リポジトリへ追加しません。

実演ごとに次を同じ解像度で保存します。

- `before_rgb.png`, `after_rgb.png`: 白板を観測する固定カメラ画像
- `board_mask.png`: 白板のみ255の二値画像
- `before_ink_mask.png`, `after_ink_mask.png`: 同一画角の全画面筆跡マスク。白板外や対象文字以外の筆跡も前後で同じ基準で保持する二値画像
- `target_roi_mask.png`: 消去対象の文字だけを囲う二値画像
- `run_metadata.json`: シミュレータ名・公式モデル版・コミット・白板寸法・カメラ校正・実行日時（個人情報を除く）

筆跡マスクは、照明条件が安定している場合はHSV/輝度しきい値で作成できます。変動が大きい場合は、消去前後ペアでラベル付けしたセグメンテーションモデルを使い、学習データと閾値をレポートに記録します。評価器の「白板外の筆跡マスク変化率」はこの二値マスクの変化だけを表し、原画像の照明・背景変化や白板損傷は測りません。
